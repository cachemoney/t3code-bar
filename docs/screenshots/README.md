# README screenshots

Both images are user-supplied screenshots of the native macOS app running with synthetic seed data:

- `macos-preview.png`: menu bar, thread statuses and an expanded last reply preview.
- `macos-usage.png`: 90-day cost, sessions, provider breakdown and daily chart.

The supplied images retain their desktop context and are used without compositing or changes to their content. All displayed usage and thread content is demo data.
