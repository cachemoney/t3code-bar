# bar-updater

`bar-updater` owns update policy for the Tauri desktop host. It does not fetch releases or install files. The host supplies the checked result from `tauri-plugin-updater`, keeps the returned `Update` object, and passes that same object to `download_and_install` after consent.

The controller preserves these rules:

- The first automatic check runs after 10 seconds. The regular check interval is 6 hours.
- Automatic check failures retry after 5 minutes, 15 minutes, and 1 hour. A fourth failure waits for the regular interval.
- A manual check only reports `Available`. It never prompts or installs.
- Automatic checks prompt by default. `install_without_asking` is an explicit setting for automatic installation.
- `prompt_shown` records a version only after the host displays its prompt. A deferred prompt remains available, and an unavailable prompt can be offered again.
- `Offer` contains a monotonic id, version, and exact tag. Installation accepts only the current offer, so a stale UI action is ignored.
- An install failure enters `Failed(Install)` and does not schedule an automatic retry.
- Source, debug, unsupported platform, missing endpoint, and missing public key builds must construct the controller with `supported = false`. The controller then reports `Unsupported` and performs no checks.

The optional `verify_signed_artifact` helper verifies the base64-wrapped Minisign values used by the plugin. The plugin also verifies the downloaded bytes before installation. The test suite uses malformed fixture values and does not contact a release service.

## Host integration

Add `bar-updater` as a path dependency in the Tauri host and add these dependencies with compatible Tauri versions:

```toml
bar-updater = { path = "../crates/bar-updater" }
tauri-plugin-updater = "2.10"
url = "2"
```

Include the plugin in the Tauri builder with `tauri_plugin_updater::Builder::new().build()`. The adapter in [`updater_adapter.rs`](../../src-tauri/src/updater_adapter.rs) shows the host wiring. It requires build-time `BAR_UPDATER_ENDPOINT` and `BAR_UPDATER_PUBLIC_KEY` values. The endpoint must be HTTPS and must return the Tauri updater manifest for the current target. The public key is the Tauri Minisign public key compiled into the build. No private key belongs in the app or repository.

Tauri artifacts must be generated by `tauri build` with updater signing enabled. macOS uses `.app.tar.gz`; Linux uses `.AppImage.tar.gz`. Do not point the Tauri endpoint at the existing Swift ZIP. Public release signing, notarization, endpoint hosting, and an end-to-end installed-app restart remain release certification gates for the host.
